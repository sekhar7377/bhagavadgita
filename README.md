# Bhagavad Gītā — The Stillness Before Action

A contemplative digital exhibition, built incrementally. **Current milestone:** original interactive symbolic bas-relief, opening narrative, reference-led generated battlefield artwork, dark menu and reflection.

```sh
npm ci
npm run dev -- --port 5173
npm run build
npm test
```

Requires Node 22.12+ (validated with Node 24.22.1). Browser tests use system Chromium at `/usr/bin/chromium` or `CHROMIUM_PATH`.

Start future sessions with [HANDOFF.md](HANDOFF.md). See [DESIGN.md](DESIGN.md) for visual intent, [creative brief](docs/CREATIVE_BRIEF.md) for the full vision, and [asset register](docs/ASSET_REGISTER.md) for source/derived media.

This is an opening prototype, not the completed 18-chapter experience. The sculpture is original procedural symbolic geometry. Final figurative art, full GPU field fidelity, chapter routes, verified Sanskrit/translation reader and audio are future milestones. Current prose is editorial, not scripture translation.
