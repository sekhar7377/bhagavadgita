# Bhagavad Gītā — The Stillness Before Action

A contemplative digital exhibition, built incrementally. **Current milestone:** an opening wall where an original Kurukṣetra bas-relief rises out of plaster under the pointer, on a GPU feedback field with lighting baked at five depths; plus the earlier prologue, battlefield artwork, dark menu and reflection.

```sh
npm ci
npm run dev -- --port 5173
npm run build
npm test
```

Requires Node 22.12+ (validated with Node 24.22.1). Browser tests use `CHROMIUM_PATH`, else `/usr/bin/chromium`, else `/opt/pw-browsers/chromium`.

Start future sessions with [HANDOFF.md](HANDOFF.md). See [DESIGN.md](DESIGN.md) for visual intent, [creative brief](docs/CREATIVE_BRIEF.md) for the full vision, and [asset register](docs/ASSET_REGISTER.md) for source/derived media.

This is an opening, not the completed 18-chapter experience. The sculpture is derived from the project's own artwork by depth estimation; it does not yet reach the hand-sculpted quality of the reference. Chapter routes, a verified Sanskrit/translation reader and audio are future milestones. Current prose is editorial, not scripture translation.
